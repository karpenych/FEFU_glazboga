# Технологии сбора и анализа больших данных

## GLAZBOGA
Генерирует IoT события и отправляет их в очередь сообщений NATS

## CONSUMER
Читает данные из очереди сообщений NATS, обрабатывает, и пишет в PostgreSQL

## REDASH
Запросы к данным и дешборд


Развертывается всё с помощью одного doker-compose файла
